모드 아이콘이 30S + 스마일로 바뀌었어요.
한 번에 여러 아이템 뽑기, 텔레포트 요청, 쉬운 안내 문구까지 듬뿍 추가!

/gives 1~3

한 번에 여러 개 뽑기

/gives 3
이제 한 번에 랜덤 아이템 3개씩 뽑아요!
[랜덤 아이템] 다이아몬드 , 사과 , 철 검 획득!
1개기본값
2개/gives 2
3개/gives 3

이제 /gives 2 하면 앞으로 한 번에 2개씩 뽑아요. 최대 3개까지, 서로 다른 아이템으로 나와요. 설정은 저장돼요.

/tpa

친구에게 텔레포트 요청

/tpa 자회
텔레포트 요청Steve님 | /tpyes 수락 / /tpno 거절
[TP] Steve님이 나한테 오고 싶어해요!
/tpyes 수락 | /tpno 거절 (60초)

상대가 /tpyes로 수락하면 내가 그 친구 옆으로 이동! /tpno로 거절할 수도 있고, 60초가 지나면 자동으로 취소돼요.

/tpon · /tpoff

텔레포트 켜고 끄기

눌러 보세요! 기본은 OFF예요. 꺼져 있으면 아무도 /tpa를 쓸 수 없고, /tpon을 하면 모두가 쓸 수 있어요.

텔레포트 OFF/tpa /tpyes /tpno 사용 불가
[TP] 텔레포트 요청이 꺼졌어요. 이제 아무도 /tpa 를 쓸 수 없어요.

켜고 끌 때는 모두에게 알림과 효과음이 나와요. 끌 때 기다리던 요청은 전부 취소돼요.

FIX

버그도 싹 고쳤어요

  • 빨리 캘 때 아이템 사라짐
    블록 채굴 모드에서 풀·꽃을 빠르게 캐면 랜덤 아이템이 지워지던 문제를 고쳤어요.
  • 지급 실패 아이템
    지급이 안 되는 아이템이 뽑히면 통째로 사라지던 걸, 다른 아이템으로 다시 뽑게 했어요.
  • 텔레포트 요청 도배
    같은 사람에게 계속 보내도 알림이 쌓이지 않아요.
  • 밀린 요청 알림
    다른 사람 요청에 밀리면 요청했던 사람에게 알려줘요.
  • 안 보이던 요청 알림
    핫바 표시에 가려지던 알림을 화면 중앙으로 옮겼어요.
  • 불러오는 중 명령어
    월드가 덜 켜졌을 때 설정이 덮어써지던 문제를 막았어요.

모드 기능

간단하게 즐기는 랜덤 아이템 생존

01

30초마다 아이템 지급

기본 설정은 30초마다 아이템을 받는 방식이에요. 시간은 /gtime으로 바꿀 수 있어요.

02

각자 다른 아이템

같은 시간에 아이템을 받아도 플레이어마다 결과가 달라요.

03

가득 찬 인벤토리도 OK

가방에 들어가지 못한 아이템은 발밑에 떨어져요.

04

남은 시간 표시

화면 아래에서 다음 아이템까지 남은 시간과 받은 아이템을 볼 수 있어요.

05

획득 효과

아이템을 받으면 이름이 나오고 효과음도 들려요.

06

블록 캐면 랜덤 드롭

/randomdrop으로 블록을 캘 때마다 랜덤 아이템이 나오는 모드로 바꿀 수 있어요.

명령어

채팅창에 / 를 누르고 입력하세요

모두누구나 쓰는 명령어 (/tpon 상태에서만)

/tpa 이름그 사람에게 텔레포트 요청 NEW
/tpyes받은 요청 수락 → 요청한 사람이 내 옆으로 와요 NEW
/tpno받은 요청 거절 NEW

OP관리자 전용 명령어

/gives 1~3한 번에 뽑을 랜덤 아이템 수 (기본 1) NEW
/tpon텔레포트 요청 켜기 NEW
/tpoff텔레포트 요청 끄기 (기본값) NEW
/random모두에게 같은 랜덤 아이템 바로 지급
/gtime 초아이템 지급 간격(초) 설정
/howmany 개수뽑은 아이템 1종당 지급 개수
/stop랜덤 아이템 지급 멈추기
/start멈춘 지급 다시 시작
/randomdrop(/stop 후) 블록 캘 때 랜덤 아이템 모드로 바꾸기
/restart(/stop 후) 시간제 모드로 돌아가기

설치 방법

몇 단계만 따라 하면 끝!

1

위의 다운로드 버튼을 눌러 파일을 받아요.

2

받은 .mcpack 파일을 열어 Minecraft로 가져와요.

3

월드 설정의 행동 팩에서 '자회의 30초 랜덤 아이템모드'를 켜요.

4

월드에 들어가면 랜덤 아이템 모드가 시작돼요.

💡 명령어는 OP(운영자) 권한이 있어야 쓸 수 있어요. 아이템 이름을 한글로 보려면 게임 언어를 한국어로 해 주세요.
